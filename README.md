## 這份研究想解決什麼？

H 公司各廠位於不同廠址，酸洗廠是盤元加工反覆經過的節點。中央生管派工後，酸洗廠將實際收料的 QR Code／條碼與本次工單串接，留下入庫、入洗、洗出及出庫紀錄，供授權角色共同查詢。

**建置動機不是假定紙本資料不正確，而是紙本更新傳遞有時間差，導致不同人員掌握的進度不同步。**

MES 的公司價值在於提供共同進度依據，支持跨廠排程、急件追查及職代交接。紙本送貨單與現場核對仍保留；球化後回到酸洗廠，也須重新建立本次入庫關聯。

## 研究主題

- **建置動機與流程：** 為何以酸洗廠入庫作為跨廠資訊串接的起點。
- **紙本與 MES 差異：** 從逐人傳遞與詢問，轉為依權限查詢共同作業紀錄。
- **驗證方法：** 優先量測資訊取得時間、角色最新狀態一致性與人工聯繫負擔；事件同步延遲需另補時間觀測。
- **資安處理：** 區分官方指引、歷史實作證據與尚需補齊的現行驗證。
