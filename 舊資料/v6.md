## 三、工作 A：同批製程串接

### 追蹤單位

以「本次入庫紀錄 ID＋本次工單關聯」追蹤同批材料。球化後回酸洗須重新串接，不只靠 QR／條碼字串合併多次入廠歷程。

1. 固定快照、查詢條件、時區及資料截止時間。
2. 篩選有效入庫明細與有效母單，分列作廢、重複及排除原因。
3. 連接本次入洗、洗出及出庫事件，保留原始 ID 的內部對照，公開時改用研究代碼。
4. 各階段分別列可追溯筆數及適用分母，另列未知、缺關聯、不適用與截止未完成。不同階段比例不必相加為 100%。
5. 截止未完成列為右設限，不能填 0 分鐘或從資料中刪除。
6. 選去識別化實際案例，比對紙本留底單、本次工單及事件時間。抽樣規則與數量先確認，不只挑成功案例。

### 異常核對

既有快照發現 5 筆入洗早於入庫、1 筆日期不一致。先查補登、修改與欄位時間語意，保留處置紀錄。兩類可能重疊，不相加推估錯誤率。單據比對是研究資料品質控制，不是將純紙本當作不正確的比較組。

### 歷程表欄位

研究案例代碼、本次工單代碼、入庫時間、入洗時間、洗出時間、出庫時間、各階段關聯狀態、截止是否完成、資料來源、異常原因、核對日期與處理方式。首次或回廠僅在有可靠欄位時分類，無法判別列「未知」。

入庫到入洗、洗出到出庫反映加工與等待安排，不能代替角色資訊同步時間。

## 四、工作 B：資訊同步與職代試測

### 觀測定義

| 代碼 | 定義 | 記錄方式 |
| --- | --- | --- |
| T0 | 現場核對完成 | 觀察員記錄實物與單據核對完成 |
| T1 | 紀錄完成 | 紙本寫好或 MES 伺服器保存成功 |
| T2,r | 角色 r 首次查見最新狀態 | 依兩組相同查核節奏觀察並留證 |
| T3,r | 角色 r 實際閱讀確認 | 另外記錄人員確認時間 |

各裝置先校準時間，記錄時區、精度與查核間隔。T2 是首次觀察到可見的時間，含查核間隔造成的誤差。不能僅用既有入庫時間推定 T0，或用 updated_at 推定 T1。

### 指標與分母

| 指標 | 定義 | 報告方式 |
| --- | --- | --- |
| 登錄延遲 | T1 − T0 | 按任務與方式報分布 |
| 可取得延遲 | T2,r − T1 | 按角色報分布 |
| 端到端同步時間 | T2,r − T0 | 中位數、配對差及有效 n |
| 人員掌握時間 | T3,r − T0 | 與 T2 分開，說明工作安排影響 |
| 最新狀態一致率 | 固定查核點一致的角色觀測數／全部應查角色觀測數 | 無權角色不納入，查無或舊版本列未同步 |
| 查詢負擔 | 同等任務耗時、詢問次數、完成率 | 未完成另列比例及觀察截止 |
| 職代交接負擔 | 查昨日已收與待辦事項的耗時、求助次數 | 控制熟悉度及任務難度 |

未同步、逾時、缺值不能填成 0 或只保留成功案例。若另列「所有角色皆一致的事件比例」，須使用事件分母，不與角色觀測分母混用。小樣本不強行解釋 P90 或顯著性。

### 紙本 VS MES 設計

| 面向 | 純紙本組 | MES 組 |
| --- | --- | --- |
| 素材 | 催料單＋入庫單及既有回報方式 | 共用系統＋相同入庫單據 |
| 任務 | 查到料、查完工、職代接手 | 等難度、不同工單的相同任務類型 |
| 人員 | 相同受測人員交叉操作 | 交錯先後順序，避免固定 MES 後做 |
| 核對 | 相同最新事件狀態作答案依據 | 相同狀態版本與判定條件 |
| 觀測 | 相同時間窗口、時鐘、查核間隔 | 相同時間窗口、時鐘、查核間隔 |

若無可靠的歷史紙本同步時間，優先討論受控配對任務，不以回憶估計當實測。試測於獨立環境或去識別化素材進行，不在正式系統重複掃碼入庫。

記錄角色、工作經驗、任務難度、工作量、急件條件、操作順序與事件代碼。同事件多角色觀測彼此相關，後續分析按事件分群，不能當作全數獨立樣本。

### 執行界線

- 正式站僅在核准範圍內唯讀盤點。不因本計畫自動取得重啟、改設定或測試攻擊的授權。
- 權限、停用帳號、逾期模擬及資料寫入測試使用獨立環境與測試帳號。
- 還原使用獨立空白環境，不覆蓋 3443／3445，不以既有展示站存在當作備援驗證。
- 遮蔽密碼、Token、內網入口、個人資料及完整客戶／訂單資訊。
- RTO／RPO 先由業務確認可接受目標，再比較實測恢復時間及可恢復資料時間點，尚未定義則列待確認。
